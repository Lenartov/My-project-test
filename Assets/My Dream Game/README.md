# Black Ridge

Нічний ралійний спецвідрізок завдовжки 1,92 км. Треба пройти три сектори за 2:25 і довезти автомобіль до фінішу. Заїзд відбувається з камери над капотом. У долині дощ і туман посилюються, а на прямій є крита галерея від каменепадів. Калюжа під одним боком може потягнути авто вбік. Сильний удар передньою частиною може збити геометрію керма, а тривале гальмування нагріває диски й знижує ефективність гальм.

## Запуск

У Unity відкрий **Tools → My Dream Game → Play Black Ridge**. Меню відкриває тимчасову сцену і запускає Play Mode. Якщо відкриті сцени мають незбережені зміни, Unity покаже діалог збереження. Якщо на момент старту всі відкриті сцени збережені, після зупинки Play Mode Unity повернеться до них.

| Клавіша | Дія |
| --- | --- |
| ↑ | Старт заїзду, газ |
| ↓ | Гальмо. Після зупинки утримуй для заднього ходу |
| ← / → | Кермо |
| Esc | Пауза або продовження |
| R | Перезапуск заїзду |
| M | Увімкнути або вимкнути музику |
| C | Увімкнути або вимкнути голос штурмана |
| G | Показати або сховати авто-привид |

Після першого фінішу гра записує заїзд і показує відставання або випередження на тій самій дистанції та на відсіченнях. Швидший фініш оновлює цей запис. Якщо в тебе був рекорд із попередньої версії, його час враховується в результатах.

## Музика

У грі звучить оригінальний трек **Black Ice**. Вибери свій локальний WAV, OGG або MP3 через **Tools → My Dream Game → Choose Music…**. Пункт **Use Original Soundtrack** повертає вбудований трек.
